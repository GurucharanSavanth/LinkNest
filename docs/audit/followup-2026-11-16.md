# Follow-up repairs — 2026-11-16

The first repair patch was committed as `750b79a` (`fix: protect library data and repair app flows`). This follow-up closes additional defects found during regression testing and supersedes the remaining-work status in the November 15 report where noted below.

## Changes

- Fixed an Add/Edit initialization crash. A cached category flow could emit while the constructor was still executing, before a callback property had initialized. A method reference removes that initialization-order dependency.
- Fixed an untouched form being marked dirty when its default category was assigned. Back navigation now returns directly; actual edits still require discard confirmation.
- Tightened metadata merge semantics. Existing destination, category, ordering, title, health state, image URLs, custom/emoji icon choice and personal fields survive failed capture. Missing metadata can be filled and tags remain combined. A different title/domain duplicate cannot silently become the saved destination. Pipeline output and mapping updates use the actual saved category/domain.
- Rejected malformed category colors at the restore boundary, preventing later editor crashes. Both six-digit RGB and eight-digit ARGB remain supported.
- Moved bulk hydration and dashboard aggregation to the existing injected default dispatcher, keeping list transformation work off the UI thread.
- Removed 47 unused resource values and the superseded widget layout after checking tracked source references. Replaced the reported URI/color calls with existing AndroidX extensions and moved the Compose runtime declaration into the version catalog.
- Wired explicit platform backup exclusions alongside the existing `allowBackup=false` policy. Manual JSON export remains the supported backup path. Separate cloud and device-transfer rules exclude app-local data and grants; Android documents that some devices treat `allowBackup=false` differently for device transfers. See [Android backup rules](https://developer.android.com/identity/data/autobackup).
